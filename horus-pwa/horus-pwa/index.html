🗺️ Carte des incidents

La carte affiche les alertes validées par les forces de l'ordre. Cliquez sur un marqueur pour voir le détail. Cliquez sur un quartier pour zoomer sur sa zone.

🚨 Signaler un incident
1
Cliquez Signaler un incident (bouton doré).
2
Choisissez la rue — le quartier se remplit automatiquement.
3
Décrivez précisément : heure, description physique, immatriculation si véhicule.
4
Votre signalement est transmis aux FDO pour validation avant publication.
⚠️ Urgence immédiate → 17 ou 112
👥 Référents de quartier

Chaque quartier a un référent citoyen bénévole. Il coordonne les alertes locales et fait le lien avec les FDO. Cliquez sur 📞 pour l'appeler directement.

📱 Installer l'application

HORUS est une PWA installable sur votre téléphone. Cliquez sur Installer l'application dans la section CTA ou via le menu de votre navigateur.

🌓 Mode clair / sombre

Cliquez sur le bouton 🌓 en haut à droite pour basculer entre le mode sombre (par défaut) et le mode clair. Votre préférence est sauvegardée.
