Guide FDO
📋 Signalements

Cliquez sur la rue d'un signalement pour ouvrir la fiche détaillée (plaque, témoins, suites). Utilisez les boutons d'action pour gérer chaque dossier.

📒 Main courante

Chaque action (validation, prise en charge…) est automatiquement enregistrée. Cliquez Exporter PDF pour générer le rapport mensuel.

📊 Statistiques

Graphiques filtrables par période, catégorie et quartier. La carte de chaleur montre la concentration des incidents. Le bouton Générer le rapport rédige un résumé narratif via l'IA.

💬 Messages

Échangez directement avec les référents de quartier. Les messages non lus apparaissent avec un badge rouge.
